# Погода по городам (wttr.in)

Консольный скрипт на Python 3.11+ (только стандартная библиотека), который читает список городов из файла `Cities.txt`, запрашивает текущую погоду через [wttr.in](https://wttr.in) и выводит данные по каждому городу, а также сводку по странам.

## Возможности

- Чтение городов из `Cities.txt` (UTF-8): удаление пустых строк и пробелов по краям, дедупликация без учёта регистра с сохранением порядка первого появления.
- Параллельные запросы к wttr.in через `ThreadPoolExecutor` (до 8 потоков), порядок вывода соответствует исходному списку.
- Таймаут запроса — 10 секунд, до 3 повторов с паузой при сетевой ошибке, заголовок `User-Agent: curl/8.0`.
- Ошибка по одному городу не прерывает работу: сообщение выводится в stderr, город исключается из статистики.
- Температура выводится с обязательным знаком: `+18`, `-5`, `+0`.
- Сводка по странам отсортирована по алфавиту: среднее (округлённое до целого), минимальная и максимальная температура.

## Формат вывода

```
=== Weather by city ===
Tokyo, Japan +18 °C
...

=== Summary by country ===
Japan — 3 cities, avg: +19 °C, min: +16 °C, max: +22 °C
...
```

Для одного города в стране используется `1 city`, для нескольких — `N cities`.

## Требования

- Python 3.11+
- Внешние зависимости не нужны (только стандартная библиотека).

## Запуск

1. Положите файл `Cities.txt` рядом со скриптом — по одному городу в строке:

   ```
   Moscow
   Khabarovsk
   Saint-Petersburg
   ```

2. Выполните:

   ```
   python main.py
   ```
